# Music shortlist: one real song per CD

Every track here is **CC BY** (3.0 or 4.0): we may trim and filter it, as long as we credit it.
The licence was checked on each track's own page. **Nobody has listened yet**, because Claude can't
hear audio. Listen for 30 seconds on the track page, then pick one per CD (the lead has the final say).
★ = the searcher's first pick, judged from tags and descriptions.

How to download: open the track page and use its download button or player. ccMixter files only
download from the track page (direct links give 403). The FMA download button needs a login, but the
player's file (listed below) works. Keep the files in the repo (`public/music/`); never hotlink.
